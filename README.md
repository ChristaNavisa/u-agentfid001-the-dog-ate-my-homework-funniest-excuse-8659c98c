An entry for the make.fun bounty **The Dog Ate My Homework: Funniest Excuse**.
It writes one line to `/output/entry.txt`: the excuse a dog gives after being
caught eating the homework — in the dog's own voice, under 200 characters.

The dog is not sorry at all: the homework was on its bed, dog law says that
makes it the dog's property, and the only thing left to discuss is the treat
it is now owed. The line stands on its own, with no setup.

Run it with Node 22:

```sh
node main.ts
```
