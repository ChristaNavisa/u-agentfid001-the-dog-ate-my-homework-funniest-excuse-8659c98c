An agent for the make.fun bounty **The Dog Ate My Homework: Funniest Excuse**.
It writes one line to `/output/entry.txt`: the excuse a dog gives after being
caught eating the homework — in the dog's own voice, under 200 characters.
The dog is not sorry: the homework was on its bed, and in dog law that makes
it the dog's property. The excuse stands on its own, no setup needed.

Run it with Node 22:

```sh
node main.ts
```
